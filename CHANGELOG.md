- **Quality guardrails, slice 1 — cross-platform + hardened CI** (2026-08-02, plan 02, issue #11): `.gitattributes` normalizes every checkout to LF (the repo's blobs were already clean — this kills the recurring Windows CRLF false-failures); the verify job becomes a 3-OS matrix (ubuntu/windows/macos) joined by a stable `ci-ok` check for branch protection; lint fails on warnings; every action is pinned by commit SHA; Dependabot watches npm + actions weekly; CodeQL scans on PR + weekly; trivy gates the Docker image on HIGH/CRITICAL vulns; Playwright uploads traces/reports as artifacts on failure; a new axe-core a11y smoke covers the agents list (both themes) and the approval-pending session view with zero-violation gates. The gate proved itself on this very PR: trivy flagged 6 fixable HIGH/CRITICAL vulns — sharp/brace-expansion fixed via scoped pnpm overrides (security floors in pnpm-workspace.yaml), and the rest lived in the base image's bundled npm CLI, which the runtime stage now deletes outright (`node server.js` never needs it). Repo settings: secret scanning + push protection + Dependabot security updates on, branch protection on `main` requiring a PR (0 approvals — review is CI + bot threads) + `ci-ok` + `docker` + resolved conversations, admins included.
- **v1 live acceptance against a real platform stack** (2026-08-02): the full loop the plan required, driven entirely through the console UI against a real compose deployment (control plane :8080, MiniMax-M3 model endpoint). Created an `always_ask`-on-`bash` agent in the editor; uploaded a file from the Files page; created a vault and sealed an `environment_variable` credential (rendered secret-free with its networking scope); created a session binding agent + environment + vault + a file mount uploaded inline; watched the SSE trace live (`user.message → status_running → span start → agent.tool_use needs-approval → status_idle requires_action`, real token counts on the span). Denied once with a message — the deny landed as an error-flagged `agent.tool_result` carrying the deny_message, and the model resumed; approved on the retry — bash ran in the executor sandbox, read the mounted file, and the agent reported its magic token before `end_turn`. Side effect confirmed the platform's observability story: `brain` and `executor` appeared in Jaeger only after this session woke them. One model-behavior quirk observed (MiniMax-M3 misread the denial text as file contents), faithfully rendered by the trace — not a console or platform defect. Closes the last open item of plan 01.
