# Changelog

## Unreleased

- **Slice 3 — live session trace + human-in-the-loop approvals** (2026-08-02): the session detail view now tails the platform's SSE stream through the BFF — seed history then attach (the wire has no replay), reconcile via a pure trace store (id-dedup across reconnect reseeds, `content_delta` appends by `(event_id, index)`, persisted events replace their streaming previews, `session.deleted` closes the trace), reconnect with backoff. Approval banner gained Allow / Deny-with-message posting `user.tool_confirmation`; a composer sends `user.message`, plain `user.interrupt`, and the batched interrupt+message redirect. `compress` disabled in next.config — gzip held back proxied SSE bytes. Mock platform grew an SSE endpoint and a session state machine (approve/deny/interrupt/streamed replies) driving 4 new e2e flows; polling event fetch retired. e2e 16/16 single-worker (the stateful mock must not interleave).

Completes the read-only half of slice 2; e2e 12/12.

Keyset pagination with a client-side prev stack (sessions use the wire's native `prev_page`), archived filters, reference-styled table primitives. Mock platform grew fixtures for all of it; e2e 9/9. Vaults/skills/files read-only pages are the remainder of slice 2.
