# Provider marks

These marks identify the model providers. Each trademark belongs to its owner.

- DeepSeek uses the blue whale from its [API documentation](https://api-docs.deepseek.com/img/favicon.svg).
- GLM uses the [Z.ai website icon](https://z-cdn.chatglm.cn/z-ai/static/logo.svg). The local SVG omits unused Illustrator color styles.
- Kimi uses Moonshot AI’s [light](https://moonshotai.github.io/Branding-Guide/scenarios/04-k-only/k-only-light.svg) and [dark](https://moonshotai.github.io/Branding-Guide/scenarios/04-k-only/k-only-dark.svg) K marks. The SVG selects the published color for the current color scheme.
- MiniMax uses the waveform in its [official model repository](https://github.com/MiniMax-AI/MiniMax-01/blob/57cf223b177e99636c7711a0f179e9fdc9c38e8a/figures/minimax.svg). See the [MiniMax brand guidelines](https://www.minimax.io/brand-vi).
