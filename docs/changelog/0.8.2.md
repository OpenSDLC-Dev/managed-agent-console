# 0.8.2 — 2026-10-12

0.8.2 is a security patch: the console image now carries **sharp 0.35.5**. The 0.8.1 image carries
sharp 0.35.4, whose bundled libvips has a HIGH librsvg advisory. On 2026-10-12, trivy 0.75.0 with
CI's gate (`HIGH,CRITICAL`, `--ignore-unfixed`) failed the published `0.8.1` image on it. Nothing in
the console's configuration feeds an SVG to sharp: librsvg parses SVG, the console sets no `images`
config, and Next.js's image optimizer refuses an SVG source before it calls sharp unless
`dangerouslyAllowSVG` is set. The reason to take it is the image scan itself.

0.8.2 is the console for **managed-agent-platform 0.5.1**, as 0.8.1 is. Coming from a platform
before 0.5.0, upgrade the console first, for the reasons
[0.8.0](https://github.com/OpenSDLC-Dev/managed-agent-console/releases/tag/v0.8.0) gives.

Validated on 2026-10-12 against managed-agent-platform 0.5.1's code (`f3c0633f`, the commit
`v0.5.1` tags), built locally with docker compose. All 11 live contracts passed, the two
model-backed ones included, and so did all 7 browser live tests: real-model bash approval and
denial, plus credential issuance and revocation.

### Changed

- The image runs Next.js 16.4.0, up from 16.3.8, with the other routine dependency updates (#210).

### Security

- Raise the `sharp` floor to 0.35.5 for a librsvg vulnerability in the image's bundled libvips
  ([GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w)).
