# 0.8.1 — 2026-10-04

0.8.1 is a security patch: the console image now runs **Next.js 16.3.8**. None of the seven
advisories it fixes is reachable in the console's configuration. There is no
`images.remotePatterns`, the console is App Router only with no root catch-all page, it has no
metadata image routes, `'use cache'` or Draft Mode, and the MCP endpoint exists only under
`next dev`. The reason to take it is the image itself: 0.8.0 ships Next.js 16.3.6, which image
scanners will flag once these advisories reach the GitHub Advisory Database. On 2026-10-04 trivy
still reported nothing against 0.8.0, because they had not reached it yet.

0.8.1 is the console for **managed-agent-platform 0.5.1**. Coming from a platform before 0.5.0,
upgrade the console first, for the reasons
[0.8.0](https://github.com/OpenSDLC-Dev/managed-agent-console/releases/tag/v0.8.0) gives. Between
0.5.0 and 0.5.1 the order does not matter: 0.5.1 changes no route and no wire type, since its
fixes are in the executor, worker and sandbox.

Validated on 2026-10-04 against managed-agent-platform 0.5.1's code (`438fc563`, the release PR's
head, whose Go tree is `9604cd5e`), built locally with docker compose. All 11 live contracts
passed, the two model-backed ones included, and so did all 7 browser live tests: real-model bash
approval and denial, plus credential issuance and revocation.
