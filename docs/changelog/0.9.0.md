# 0.9.0 — 2026-11-18

Console 0.9.0 requires the platform's native login and one-origin application edge.
Upgrade the platform edge before replacing a legacy Console. Follow the
[upgrade procedure](../../docs/deploy-gcp.md#upgrade-boundary).

Staging accepted Console revision `8158c6a` on platform revision `5687be6`.
The operator signed in with Google, opened Models and Service accounts, and received
a model reply in a new session. Usage showed the initiating principal, session and
token counts for that request. The last documented full live-tier pass was Console
0.8.2 against platform 0.5.1. For the native-only build, the current evidence is the
native browser suite and this staging acceptance.

### Added

- Platform login supports setup-code redemption, member administration and the
  service-account lifecycle through the application edge.
- Developers can issue API keys for themselves. Administrators can also issue them
  for active service accounts. Each key follows its owner's current role.
- Administrators can issue and revoke keys for cloud and self-hosted environments,
  including archived environments. Cloud key management omits worker setup instructions.
- Administrators can select an active service account to initiate future scheduled
  deployment runs. Manual runs keep the caller, and editing the setting leaves a
  paused deployment paused.
- Model Gateway manages providers, write-only vendor credentials, upstream models
  and public model routing. An empty gateway offers a guided setup flow. The Agent
  and Dream model pickers show the gateway's chat models where available.
- Analytics → Usage shows request, error, token and cost totals, plus daily breakdowns
  and a request ledger. Operators can filter by principal, key, model or upstream model.
  Historical requests retain their stored attribution.
- The model inspector shows shared organization limits for requests, input tokens
  and output tokens per public alias. Administrators can update or clear the limits.
- The trusted-main SHA image channel publishes scanned amd64 and arm64 builds for
  staging. See the [SHA publication procedure](../../docs/releasing.md#non-release-sha-channel).

### Changed

- Browser requests use the platform's session cookie and CSRF contract, including
  streams and downloads. Console-local password and OIDC handling, the credential
  proxy and legacy per-key model policies have been removed.
- The platform owns staging rollout and rollback. The Console repository publishes
  images. See [deployment ownership](../../docs/deploy-gcp.md).
- The sidebar displays the Console version beneath the wordmark and uses title case
  for navigation labels.
- The dependency update includes Lucide React 1.73.0, Playwright 1.65.1 and jsdom 31.0.1. [#264](https://github.com/OpenSDLC-Dev/managed-agent-console/pull/264)

### Fixed

- Navigation, Dashboard and Search hide resources after a confirmed read refusal.
  Bookmarks explain the denial. Confirmed role changes refresh available actions
  and clear stale key and model-limit drafts.
- The key row menu exposes permanent revocation as Delete. Key forms support retrying
  an unavailable service-account directory while preserving the draft.
- Memory browsing handles a terminal empty page and clears the prefix filter when
  the path field is empty. Recursive lists omit depth.
- Search, calendar days, vault selectors, resource previews and timeline zoom keep
  visible labels in accessible control names.
- CI collects Playwright reports and failed-attempt artifacts after successful
  retries. Native fixture checks allow for slow startup and Windows scheduling.
