# 0.9.1 — 2026-11-19

Console 0.9.1 hardens tool approvals, account transitions and release publishing.
It requires the platform's native login and one-origin application edge. Follow
the [upgrade procedure](../../docs/deploy-gcp.md#upgrade-boundary) when replacing
a legacy Console.

The last documented full live-tier pass was Console 0.8.2 against platform 0.5.1.
The native-login staging acceptance used Console revision `8158c6a` and platform
revision `5687be6`.
[0.8.2 live-tier results](../../docs/changelog/0.8.2.md) ·
[Staging acceptance](../../docs/HISTORY.md#platform-plan-69-native-only-console-acceptance)

### Fixed

- Tool approvals show the execution inputs and MCP server. Console documents deny framing.
- Account changes block stale writes. Sign-out hides private content and offers recovery if revocation is unconfirmed.
- Live browser tests suppress credential-bearing diagnostics. Release jobs publish only a verified release commit from `main`.
