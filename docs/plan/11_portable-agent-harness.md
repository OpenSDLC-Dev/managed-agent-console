# Portable project instructions

Keep repository agreements in `AGENTS.md` and author rules, skills, role instructions and hook policies in `harness/`. Commit regular native adapter files so Windows, macOS and Linux clones can start without installing packages. Node provides the doctor independently of the platform checkout.

Each new CLI session checks its host before work. CI checks all hosts offline. Repair reproducible drift during writable tasks. Preserve local settings and ask for the source of an unregistered hook. Start review in a fresh context that inherits the developer model and reasoning setting. Validate the effective settings when accepting a review.
