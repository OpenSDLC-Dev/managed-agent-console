# Portable project instructions

Keep repository agreements in `AGENTS.md` and author rules, skills, role instructions and hook policies in `harness/`. Commit regular native adapter files so Windows, macOS and Linux clones can start without installing packages. Node provides the doctor independently of the platform checkout.

Look for the current session's independent `SessionStart` receipt before work. If it is missing, run `node scripts/harness-doctor.mjs check` and verify the hook separately in a fresh trusted session. Claude started in a subdirectory may need to restart at the worktree root or load that root's settings explicitly. CI checks all hosts offline.

Repair reproducible drift during writable tasks. Preserve local settings and ask for the source of an unregistered hook. Start review in a fresh context that inherits the developer model and reasoning setting. Validate the effective settings when accepting a review.
