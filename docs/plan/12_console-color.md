# Console color audit

On 2026-11-28 we compared signed-in Claude Console in Chrome with the self-hosted rendering paths at `e522f51`. The hosted session used light mode. The dark palette is a self-hosted adaptation of the observed color roles. The comparison covers the surfaces that render graphics or code, including shared renderers used by detail drawers.

Keep the sidebar and search icons neutral.                                                                                                                                              |
