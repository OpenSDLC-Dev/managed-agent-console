## Repeat the comparison

1. Open Agents from the desktop sidebar. Select Default, dismiss the picker with Escape, return to all sections and re-enter. Open Agents overview from console search.
2. Open each metric explanation and Create menu item. Hover a chart and use its arrow keys. Sort Name, Sessions, Error rate and Last active in both directions. Open a row, View sessions, Show more and the resource links. Check empty data separately from a failed report.
3. On Create, open and dismiss each template. Change the code format, copy it, then try the blank agent link. For a selected template or a description, edit the draft, try invalid YAML, refine and cancel a navigation. Confirm once and inspect the new ID, environment selection, session and exported configuration.
4. The browser suite uses a signed-in local fixture. Model generation is replayed, and test writes are isolated in the fixture. Run `pnpm test:e2e` for the complete suite or `pnpm exec playwright test test/e2e/agents-workspace.spec.ts` against a freshly built Console. The Chrome fidelity manifest includes the workspace overview, template grid, preview, editable draft, saved setup and the Observability tab. Platform's `TestAgentsWorkspaceOverview` exercises PostgreSQL window boundaries, last-turn recovery, session clocks, rankings and tenant isolation.

The hosted acceptance run created one uniquely named plain-text summarizer, verified its version and archived it by ID. It stopped before provisioning an environment or starting a session.
