## Repeat the comparison

1. Open Agents from the desktop sidebar. Select Default, dismiss the picker with Escape, return to all sections and re-enter. Open Agents overview from console search.
2. Open each metric explanation and Create menu item. On desktop and at 375 px wide, check that the menu aligns with the right edge of Create and all five actions fit on single lines. Use End to focus Memory store and Escape to return focus to Create. Hover a chart and use its arrow keys. Sort Name, Sessions, Error rate and Last active in both directions. Open a row, View sessions, Show more and the resource links. Check empty data separately from a failed report.
3. On Create, open and dismiss each template. Change the code format, copy it, then try the blank agent link. For a selected template or a description, edit the draft, try invalid YAML, refine and cancel a navigation. Confirm once and inspect the new ID, environment selection, session and exported configuration.
4. The browser suite uses a signed-in local fixture. Model generation is replayed, and test writes are isolated in the fixture. Run `pnpm test:e2e` for the complete suite or `pnpm exec playwright test test/e2e/agents-workspace.spec.ts` against a freshly built Console. The Chrome fidelity manifest includes the workspace overview, template grid, preview, editable draft, saved setup and the Observability tab. Platform's `TestAgentsWorkspaceOverview` exercises PostgreSQL window boundaries, last-turn recovery, session clocks, rankings and tenant isolation.

The hosted acceptance run created one uniquely named plain-text summarizer, verified its version and archived it by ID. It stopped before provisioning an environment or starting a session.

### Directory creation regression

1. From **Agents → Agents**, follow **Create agent**. Check the breadcrumb, starter defaults, model menu, collapsed optional groups and footer on desktop and at 390 px. Follow **Memory** and **Credential vaults** back to their original destinations. Search for the full resource name **Memory Stores** and open the **Memory** shortcut.
2. Select all six starting templates. Verify their summaries and fields. Change the model, effort and speed, configure tools and skills, then inspect and copy the same draft in YAML and JSON. Change the model directly in Raw and apply another template. Confirm it keeps the selected model and reports invalid Raw input without replacing the draft. In Rendered, leave a custom tool schema unfinished. Choose another template and exercise both Stay and Leave.
3. Replay a failed and a successful Generate response. Confirm that previewing and generating send no agent write. Create once and reopen the saved configuration. The directory scenarios run in `test/e2e/agent-manual-create.spec.ts`, `agent-editor.spec.ts` and `agent-unsaved.spec.ts`.
